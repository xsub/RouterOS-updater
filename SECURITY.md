# Security

This development-stage updater can modify and restart network infrastructure.
Test on non-production equipment before enabling unattended changes.

For a potential vulnerability, use GitHub private vulnerability reporting when
available. Never post real credentials, device identifiers, SSH keys, exports or
private network details in public issues. Use synthetic reproduction data.

The trust boundary and integration limitations are in [docs/DESIGN.md](docs/DESIGN.md).
Device recovery and firmware rollback need a separate operational procedure.
